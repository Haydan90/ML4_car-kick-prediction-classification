# ML4: Бинарная классификация и оценка некачественных подержанных авто (`ML4_car-kick-prediction-classification`)

В рамках проекта решается задача бинарной классификации на датасете **Kaggle: [Don't Get Kicked](https://www.kaggle.com/c/DontGetKicked)** — определение того, является ли купленный на аукционе подержанный автомобиль некачественным (неисправным / «лимоном»).

---

## 1. Содержание и структура проекта

1. **Разделение по времени (Time-based Split):**
   - Разделение данных на `train`, `valid` и `test` по дате покупки (`PurchDate`), чтобы исключить утечку данных из будущего.
2. **Предобработка и пайплайны (`scikit-learn`):**
   - Импутация пропущенных значений (медиана для числовых, мода для категориальных).
   - Масштабирование числовых признаков (`MinMaxScaler`).
   - Кодирование категориальных признаков (`OneHotEncoder`).
3. **Реализация и сравнение базовых алгоритмов:**
   - Логистическая регрессия, Наивный Байес и метод $k$-ближайших соседей ($KNN$).
   - Написание собственных кастомных версий алгоритмов с нуля (`MyLogisticRegression`, `MyGaussianNB`, `MyKNN`).
4. **Инженерия признаков и регуляризация:**
   - Генерация нелинейных признаков (`odo_per_age`, `cost_to_retail`, `warranty_to_cost`).
   - Сравнение ручного отбора, $L_1$-регуляризации и подбора гиперпараметров ($C$ для LogReg, $k$ для KNN, `var_smoothing` для Bayes).

---

## 2. Анализ результатов и выводы по моделям

- **Логистическая регрессия (с $L_1$-регуляризацией):** Показала лучший результат (`Gini = 0.3312` на валидации, `0.3525` на тесте). После One-Hot Encoding пространство признаков становится высокоразмерным и разреженным, а линейные модели отлично справляются с разделением таких гиперплоскостей. $L_1$-регуляризация помогла эффективно занулить слабые признаки и улучшить качество.
- **KNN ($k$-ближайших соседей):** На разреженных категориальных данных после OHE расстояния между объектами становятся менее информативными, а алгоритм сильно чувствителен к шуму, из-за чего результаты оказались скромнее.
- **Наивный Байес:** Показал низкую эффективность, так как ключевое предположение модели о независимости признаков в данном датасете явно не выполняется (многие характеристики машин коррелируют друг с другом).

## 5. Как запустить проект

1. Клонировать репозиторий:
   ```bash
   git clone [https://github.com/Haydan90/ML4_car-kick-prediction-classification.git](https://github.com/Haydan90/ML4_car-kick-prediction-classification.git)
   cd ML4_car-kick-prediction-classification
   ```
2. Скачать датасет с [Kaggle: Don't Get Kicked](https://www.kaggle.com/c/DontGetKicked) и поместить `training.csv` в директорию `data/`.
3. Установить зависимости:
   ```bash
   pip install numpy pandas scipy scikit-learn jupyter
   ```
4. Запустить Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
```
